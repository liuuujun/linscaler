当前 0.1.0 处于预发布阶段，尚未公开发布，不承诺 API 稳定。准备首个正式稳定版本 1.0.0 前，代码和 CMake 版本保持 0.1.0。本地实现不会自动发布仓库。托管 CI 配置和历史结果不能证明当前代码已通过 CI。索引区间、输入范围反查和补偿计算仍是未来候选能力，不是已完成功能。

## 源码材料

源码分发应包含 `include`、`tests`、`examples`、`cmake`、`scripts`、`docs`、
公共项目配置、许可证及根目录双语文档。不要直接压缩整个工作目录：`.gitignore`
不会过滤 ZIP 工具。排除 `out`、`build`、`.tools`、`.vs`、CMakeUserPresets.json
及生成的 CMake 文件；本地验证日志及可能存在的 legacy-source 快照应原地保留。
初始化 Git 后，提交前检查暂存文件清单。`.gitattributes` 的导出规则还会让
`git archive` 排除本机材料及 `AGENTS.md`，但不会从已有提交中移除文件。
